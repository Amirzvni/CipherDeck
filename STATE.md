## Phase 1 — Core engine (CipherDeckCore) ✅
- ✅ Base32 decode/encode (tolerant of spaces, lowercase, missing padding)
- ✅ HOTP (RFC 4226) / TOTP (RFC 6238) — SHA1/256/512, 6–8 digits, custom period
- ✅ `otpauth://` URI parse + build
- ✅ Google Authenticator `otpauth-migration://` protobuf decode (import) + encode (export)
- ✅ Encrypted vault (AES-256-GCM, atomic write, `.bak` fallback, versioned)
- ✅ Encrypted backup files (PBKDF2-SHA256 600k + AES-GCM)
- ✅ Import parser (text files of URIs / migration links) + de-dupe merge
- ✅ Self-test suite with RFC vectors & real migration payloads (613 checks, incl. 20k-case protobuf fuzz, vault tamper/recovery)

## Decisions log
- **2026-09-22** — Name *CipherDeck* (a netrunner's "cyberdeck" for your ciphers). Native
  Swift over Electron/Tauri: smallest attack surface, Keychain/Touch ID/Vision native, tiny
  binary, no JS supply chain.
- **2026-09-22** — Vault key in the login Keychain (not data-protection keychain) because
  that requires a Team ID, which the owner doesn't have.
- **2026-09-22** — Tests are an executable target (`CipherDeckSelfTest`): the installed
  Command Line Tools ship neither XCTest nor swift-testing, and Xcode's license isn't accepted.
